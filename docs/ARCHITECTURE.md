## 📦 Архитектурные слои

### Уровень 1: Точка входа (main_run.py)
- **Назначение:** Запуск приложения на порте 8000
- **Использует:** Uvicorn ASGI сервер
- **Импортирует:** `src.app:app`

### Уровень 2: Маршруты (src/app.py)
- **Назначение:** Определение всех REST API endpoints
- **Маршрутов:** 7 основных + 2 вспомогательных
- **Использует:** Pydantic модели

### Уровень 3: Модели (src/models.py)
- **Назначение:** Валидация данных
- **Классы:**
  - `User` - пользователь (Задание 1.4)
  - `UserAge` - пользователь с возрастом (Задание 1.5)
  - `UserAgeResponse` - ответ с is_adult (Задание 1.5)
  - `Feedback` - отзыв с валидацией (Задания 2.1, 2.2)

### Уровень 4: Представление (src/templates/)
- **index.html** - страница для Задания 1.2
- **test.html** - интерактивный интерфейс тестирования

## 🎯 Маршруты и их назначение

| Маршрут | Метод | Задание | Описание |
|---------|-------|---------|---------|
| `/` | GET | 1.1 | Возвращает JSON приветствие |
| `/html` | GET | 1.2 | Возвращает HTML страницу |
| `/calculate` | POST | 1.3 | Складывает два числа (query params) |
| `/users` | GET | 1.4 | Возвращает User модель |
| `/user` | POST | 1.5 | Проверяет возраст, возвращает is_adult |
| `/feedback` | POST | 2.1/2.2 | Сохраняет отзыв с валидацией |
| `/feedbacks` | GET | - | Возвращает все сохранённые отзывы |
| `/test` | GET | - | Интерактивная страница тестирования |

## 🔐 Безопасность

### Валидация данных
1. **Feedback.name:** 2-50 символов
2. **Feedback.message:** 10-500 символов
3. **Запретные слова:** "кринж", "рофл", "вайб" - блокируются
4. **Type checking:** Pydantic автоматически проверяет типы

### HTTP статусы
- **200 OK** - успешный запрос
- **422 Unprocessable Entity** - ошибка валидации

## 🚀 Процесс запуска

```
1. python3 main_run.py
   ├─ Загружает src.app:app
   │
2. FastAPI инициализируется
   ├─ Импортирует модели из src.models
   ├─ Регистрирует 9 маршрутов
   │
3. Uvicorn запускает ASGI сервер
   └─ Слушает на 0.0.0.0:8000
```

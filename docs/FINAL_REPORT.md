- **Маршрут:** `POST /calculate?num1=X&num2=Y`

- **Результат:** `{"result": сумма}`
- **Файл:** `src/app.py` (функция `calculate()`)
- **Статус:** ✅ Работает с HTTP 200

### ✅ Задание 1.4 - GET /users (Модель User через Pydantic)
- **Маршрут:** `GET /users`

- **Результат:** `{"name": "Дарья Невская", "id": 1}`
- **Modель:** `User` в `src/models.py`
- **Статус:** ✅ Работает с HTTP 200

### ✅ Задание 1.5 - POST /user (Проверка совершеннолетия)
- **Маршрут:** `POST /user` (JSON body)
- **Входные данные:** `{"name": "...", "age": ...}`
- **Результат:** `{"name": "...", "age": ..., "is_adult": true/false}`
- **Логика:** is_adult = (age >= 18)
- **Модели:** `UserAge`, `UserAgeResponse` в `src/models.py`
- **Статус:** ✅ Работает с HTTP 200/201

### ✅ Задание 2.1 - POST /feedback (Отозвы)
- **Маршрут:** `POST /feedback` (JSON body)
- **Входные данные:** `{"name": "...", "message": "..."}`
- **Результат:** `{"message": "Спасибо, ...! Ваш отзыв сохранён."}`
- **Хранилище:** В памяти сервера (feedbacks list)
- **Модель:** `Feedback` в `src/models.py`
- **Статус:** ✅ Работает с HTTP 201

### ✅ Задание 2.2 - POST /feedback (Валидация отзывов)
- **Маршрут:** `POST /feedback` (тот же что 2.1)
- **Валидация имена:** минимум 2 символа, максимум 50
- **Валидация сообщения:** минимум 10 символов, максимум 500
- **Запретные слова:** `кринж`, `рофл`, `вайб` (блокируются)
- **Ошибка валидации:** HTTP 422 с деталями
- **Реализация:** `@field_validator` в Pydantic модели
- **Статус:** ✅ Валидация работает корректно

## 🔍 Особенности реализации

### Особенность 1: Pydantic валидация
Запретные слова проверяются на уровне модели, а не в маршруте:
```python
@field_validator('message')
@classmethod
def check_forbidden_words(cls, v: str) -> str:
    forbidden_words = ['кринж', 'рофл', 'вайб']
    for word in forbidden_words:
        if word in v.lower():
            raise ValueError(f'Слово "{word}" запрещено в отзывах')
    return v
```

### Особенность 2: Хранение feedback в памяти
Отзывы хранятся в простом Python list:
```python
feedbacks = []

@app.post("/feedback")
def submit_feedback(feedback: Feedback):
    feedbacks.append({"name": feedback.name, "message": feedback.message})
    return {"message": "Спасибо!"}
```

### Особенность 3: Поддержка Swagger автоматически
FastAPI автоматически генерирует Swagger документацию из:
- Декораторов маршрутов
- Type hints функций
- Docstrings
- Pydantic моделей

# 🧪 Быстрое руководство по тестированию

## ⚡ За 2 минуты

### Шаг 1: Запускаем приложение
```bash
python3 main_run.py
```
Сервер запустится на **http://localhost:8000**

### Шаг 2: Открываем тестирование
Открой в браузере:
- 🧪 **Интерактивное тестирование:** http://localhost:8000/test
- 📚 **Swagger API доки:** http://localhost:8000/docs

### Шаг 3: Какие кнопочки потыкать на `/test` странице

#### Задание 1.1 - Приветствие
- Нажми кнопку "Тест"
- Получишь JSON: `{"message": "Авторелоад действительно работает"}`

#### Задание 1.2 - HTML 
- Нажми кнопку "Открыть"
- Откроется HTML страница с текстом "Я ОБОЖАЮ ВСТАВАТЬ К ПЕРВОЙ ПАРЕ :)"

#### Задание 1.3 - Сумма чисел
- Введи в "Первое число": **10**
- Введи в "Второе число": **5.5**
- Нажми "Тест"
- Получишь: `{"result": 15.5}`

#### Задание 1.4 - Получить пользователя
- Нажми кнопку "Тест"
- Получишь: `{"name": "Дарья Невская", "id": 1}`

#### Задание 1.5 - Проверка возраста
- Введи в "Имя": **Иван**
- Введи в "Возраст": **25**
- Нажми "Тест"
- Получишь: `{"name": "Иван", "age": 25, "is_adult": true}`

**Про возраст:**
- Возраст < 18 → `is_adult: false`
- Возраст >= 18 → `is_adult: true`

#### Задание 2.1/2.2 - Отправить отзыв (с валидацией!)
- Введи в "Имя": **Маша** (2-50 символов)
- Введи в "Отзыв": **Отличное приложение, очень доволен работой!** (10-500 символов)
- Нажми "Отправить"
- Получишь: `{"message": "Спасибо, Маша! Ваш отзыв сохранён."}`

**Проверь валидацию (попробуй запретные слова):**
- Напиши в отзыве слово **"кринж"** → получишь ошибку HTTP 422 ✓
- Напиши слово **"рофл"** → ошибка HTTP 422 ✓
- Напиши слово **"вайб"** → ошибка HTTP 422 ✓

## 🔊 Ошибки валидации (это ПРАВИЛЬНО!)

Если ты видишь **HTTP 422** ошибку - это значит что валидация работает правильно!

Примеры ошибок:
- Имя слишком короткое (< 2 символов) → 422
- Сообщение слишком короткое (< 10 символов) → 422
- Слово "кринж" в сообщении → 422
- num1 или num2 - не число (в Задании 1.3) → 422

Это **часть Задания 2.2** - валидация должна отклонять неправильные данные!
